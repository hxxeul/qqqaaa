02 / WIRING

핀 번호 그대로 연결하기

준비물: Arduino Uno R3, 빨강·노랑·초록 LED 각 1개, 330Ω 저항 3개, 순간 누름 버튼 1개, 저전류 수동 피에조 부저 1개, 브레드보드, 점퍼선, USB 케이블.

부품Arduino 핀연결 방법
빨강 LEDD13D13 → 330Ω → LED 긴 다리(+) / 짧은 다리(−) → GND
노랑 LEDD12D12 → 330Ω → LED 긴 다리(+) / 짧은 다리(−) → GND
초록 LEDD11D11 → 330Ω → LED 긴 다리(+) / 짧은 다리(−) → GND
버튼D2누를 때 연결되는 두 접점 → D2와 GND
수동 피에조 부저D8부저 (+) → D8 / 부저 (−) → GND
D13 ── [330Ω] ── 빨강 LED (+ → −) ── GND
D12 ── [330Ω] ── 노랑 LED (+ → −) ── GND
D11 ── [330Ω] ── 초록 LED (+ → −) ── GND
D2  ── [버튼: 누르면 연결] ────────── GND
D8  ── 수동 피에조 부저 (+ → −) ──── GND

버튼은 INPUT_PULLUP

내부 풀업 저항을 사용합니다. 평소에는 HIGH, 누르면 LOW입니다. 이 구성에서는 버튼에 외부 풀업 저항이나 5V 선을 추가하지 않습니다.

4핀 버튼은 내부적으로 두 핀씩 연결되어 있습니다. 핀 방향만으로 판단하지 말고, 누르기 전에는 끊어져 있다가 누르면 연결되는 접점 쌍을 사용하세요.

LED와 부저 확인

LED마다 저항을 하나씩 사용하고 모든 GND를 공통으로 연결하세요. 배선을 바꿀 때는 USB 전원을 분리하세요.

멜로디에는 수동 피에조 부저가 필요합니다. 능동 부저는 음높이 재현이 어렵습니다. 일반 스피커나 전류가 큰 부저는 D8에 직접 연결하지 말고 적절한 구동 회로를 사용하세요.

03 / ARDUINO SKETCH

복사해서 업로드하는 전체 코드

millis()로 LED 시간과 멜로디를 함께 관리합니다. 버튼에는 30ms 디바운스를 적용했고, 별도 라이브러리나 pitches.h 파일은 필요 없습니다.

traffic_light.ino · 재구성 버전

업로드 순서

  1. 배선 확인 후 USB로 보드를 연결합니다.
  2. Arduino IDE에서 새 스케치를 엽니다.
  3. 아래 전체 코드를 복사하여 붙여 넣습니다.
  4. 보드 Arduino Uno와 연결된 포트를 선택합니다.
  5. 검증 후 업로드하고 버튼을 눌러 확인합니다.

멜로디 바꾸기

melody[]에는 주파수(Hz)를 넣습니다. 예시는 262, 330, 392, 523, 즉 도–미–솔–높은 도입니다. 0은 쉼표입니다.

NOTE_STEP_MS = 250은 음표 간격, NOTE_ON_MS = 180은 실제 소리가 나는 시간입니다. 소리 길이는 음표 간격보다 짧게 설정하세요.

04 / CHECK & LEARN

확인하면 좋은 것들

버튼을 안 눌러도 시작된다면

D2가 GND에 계속 연결되어 있는지 확인하세요. 4핀 버튼에서 항상 연결된 두 핀을 선택했을 수 있습니다. 이 코드는 전원을 켤 때 이미 누른 버튼도 한 번의 입력으로 처리합니다.

LED가 켜지지 않는다면

LED 극성, 저항, 브레드보드 행과 GND 연결을 확인하세요. Uno의 내장 LED도 D13에 연결되어 있어 빨간불과 함께 켜질 수 있습니다.

소리가 나지 않는다면

부저 종류와 극성, D8 연결을 확인하세요. HTML 시연은 기기 음량과 ‘예시 멜로디 듣기’ 선택 여부도 확인하세요.

D11과 tone()을 함께 써도 되나요?

Uno에서 tone()은 D3·D11의 PWM 출력에 영향을 줍니다. 이 코드는 밝기 조절용 analogWrite() 대신 켜기·끄기용 digitalWrite()를 사용합니다.

검증 범위: 파일의 코드 구성과 상태 전환 논리를 점검했습니다. 실제 Arduino 보드에서의 컴파일·업로드·배선 시험은 수행하지 않았습니다. 실제 전환 시간에는 루프 처리에 따른 미세한 오차가 있을 수 있습니다.

공식 참고: Arduino INPUT_PULLUP · Arduino tone() 레퍼런스. 페이지 본문과 시연은 인터넷 없이 작동하며, 참고 링크만 인터넷 연결이 필요합니다.
